# Privacy policy: MVP YouTube Uploader

Last updated: November 22, 2026

MVP YouTube Uploader is a private tool used only by the owner of Modern Vista Prints to upload and schedule the shop's own videos to the shop's own YouTube channel.

## What the tool accesses
With the owner's permission, the tool uses the YouTube Data API scope `youtube.upload` to upload videos and set their title, description, tags and publish time on the owner's channel. It uses YouTube API Services; see the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy).

## What the tool collects
The tool has no public users and collects no personal information from anyone. It does not read viewers' data, comments or analytics. It stores only the owner's own sign-in tokens, kept as private settings and never shared or sold.

## Removing access
The owner can remove the tool's access at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
