# MVP YouTube Uploader

MVP YouTube Uploader is a private, internal tool of Modern Vista Prints, an Etsy shop of vintage travel posters. The shop owner uses it to upload and schedule the shop's own short videos to the shop's own YouTube channel.

The tool is not offered to the public. Only the shop owner signs in to it.
