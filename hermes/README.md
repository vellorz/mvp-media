# Shared marketing brain

Notes the three ModernVistaPrints agents leave for each other:

- `handoff/` - the Marketing agent (Claude) writes a weekly handoff: plan, post IDs, what worked.
- `research/` - the Research agent (local Qwen) writes keyword and buyer research.
- `insights/`, `experiments/`, `targets/` - research board items (format: Mission Control `hermes-setup/research-board-format.md`).
- `approvals/` - requests waiting for the owner.

The Chief of staff (Hermes) coordinates the agents on the Hermes Kanban board; this folder is the long-form record.
