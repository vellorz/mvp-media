# ModernVistaPrints: what we've learned

The team's running memory of what works. **Every agent reads this before planning** (the Chief, Research, Marketing and the weekly Claude routine), and adds to it when a result comes in. Newest first. Edit an older lesson when new evidence confirms or overturns it, instead of adding a duplicate.

The goal behind every lesson: **grow the business**. The north star is Etsy orders; visits, views and saves are steps toward them.

## How to write a lesson

```
## YYYY-MM-DD · short name of the lesson
- tried: what we did, where, for how long (one line)
- result: the numbers before → after, with the source (dashboard screen, Buffer, Etsy Stats, file name)
- verdict: keep | drop | retest
- confidence: low | medium | high (low when traffic was tiny or only one week was measured)
- next: what to do because of it (one line)
```

Rules:
- Real numbers only, with where they came from. If there was no measurement, write "not measured", never a guess.
- Traffic is small (often fewer than 20 visits a week across many listings), so one week is weak evidence. Mark it low confidence and retest before treating it as a rule.
- A before/after change is not proof of cause. Seasonality, posting days and Etsy's own changes move numbers too.
